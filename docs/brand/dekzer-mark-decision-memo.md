# Dekzer mark decision memo

Recommended filename: docs/brand/dekzer-mark-decision-memo.md

## Status

The current D/K/R monogram is the canonical Dekzer mark direction.

This is no longer a logo exploration track. Future work is production refinement only.

## Core decision

The mark is not required to make D, K, and R equally legible.

Correct read hierarchy:

1. Primary read: sharp abstract Dekzer symbol
2. Secondary read: D + K monogram
3. Identity spine: diagonal slash as needle, Z, motion, cut, transition
4. Discovered read: R

The R is intentionally secondary/tertiary. Do not force it into first-read status if doing so weakens the mark.

## Structural diagnosis

The R is weak because the D is open on the right.

That openness is also what makes the D/K interlock work.

The same geometry that helps the mark also limits the R. This is not a bug to blindly fix. It is a tradeoff to preserve
unless evidence proves otherwise.

## Highest-priority invariant

The diagonal slash is the strongest identity element.

It must survive every version.

It carries:

- vinyl needle / tonearm read
- Z read
- motion
- sharpness
- transition energy
- the central identity of the mark

Do not weaken, reposition, soften, or over-explain the slash.

## Locked geometry invariants

Preserve:

- left D frame
- open internal counter
- K structure
- central diagonal slash angle
- pointed needle energy
- fragile hidden R suggestion
- current overall silhouette
- sharp angular language
- strong white/black monochrome viability

Do not casually skew, rebalance, round, decorate, add extra cuts, or make the mark more literal.

## R legibility policy

Do not redesign the master to make the R obvious.

Accept the R as a discovered read.

The R should reward attention, not dominate the first impression.

The master is locked. The only allowed structural experiment is a single controlled partial-bowl-closure A/B test. That
test does not reopen the design direction. Its only possible outcomes are adopt or discard.

### Controlled A/B candidate: partial bowl closure

A partial bowl closure means a minimal mid-right return that slightly hints at an R bowl without clogging the mark or
damaging the slash corridor.

This is not approved by default.

Pass criteria:

- slash corridor remains unaffected
- first-read personality remains indistinguishable from the locked master
- D/K clarity is not reduced
- Z/needle read is not reduced
- internal counter does not clog
- mark still feels sharp, fast, and abstract
- R clarity improves enough to matter in actual use

Automatic discard criteria:

- no meaningful gain in R clarity
- slash feels weaker
- mark becomes visually heavier in the center
- mark starts reading as a forced letter puzzle
- hidden R improves only by damaging the primary symbol

Rejected directions:

- moving the slash to become an explicit R leg
- redesigning the whole skeleton around an R
- making the mark a literal D/K/R puzzle
- adding geometry only to explain the R

## Z policy

The Z read is underrated and must be protected.

The slash compresses Dekzer visually: D, K, Z, hidden R.

That gives the mark a stronger brand-specific logic than a plain D/K monogram.

The Z/needle slash is more important than making the R obvious.

## Variant system

Use three tiers.

### Tier A: canonical master

Use at normal and large sizes.

Applies to:

- app icon master
- splash screen
- website
- docs
- social avatar where size is sufficient
- product surfaces
- wordmark lockups

Rule:

Use the locked master geometry.

### Tier B: small-size optical compensation

Use where the full mark still fits but needs pixel survival.

Working hypothesis pending export validation:

- 24 px
- 32 px
- possibly 16 px only after testing

Allowed adjustments:

- slightly reinforce fragile joins
- slightly protect the needle tip
- slightly increase stroke weight where pixels disappear
- keep internal counters open
- maintain the same silhouette

Rule:

This is not a second logo. It is the same mark tuned for rendering conditions.

### Tier C: reduced production mark

Use only for extreme constraints.

Applies to:

- favicon
- tiny taskbar contexts
- laser etching
- hardware marking
- embroidery
- tiny print
- low-resolution displays

Rule:

Do not keep scaling the full mark if it fails. Create a purpose-built reduced mark.

The reduced mark must inherit from the same identity spine. It must preserve the slash character and enough
left-frame/monogram logic to feel related.

This is not a second logo. It is a constraint-specific reduction of the same identity system.

## Minimum size policy

These thresholds are working hypotheses only. They are not final rules until validated by real exports.

Preliminary hypotheses:

- 64 px and up: canonical master likely holds
- 32 px: canonical master likely holds unless tests show loss
- 24 px: likely optical compensation
- 16 px: likely optical compensation or reduced mark
- below 16 px: reduced mark likely required

Final thresholds must be based on actual rendered exports, not theory.

## Testing requirements

Test the mark at:

- 16 px
- 20 px
- 24 px
- 32 px
- 48 px
- 64 px
- 128 px
- 256 px

Test contexts:

- black background with white mark
- white background with black mark
- transparent background
- light-mode UI
- dark-mode UI
- Windows taskbar
- browser favicon
- app title/dock context
- documentation embed
- monochrome print
- low-contrast preview
- hardware-style engraving simulation

Pass criteria:

- recognizable silhouette
- slash survives
- no muddy white knot
- internal openings do not collapse
- mark remains optically centered
- small version still feels like the same mark
- inverted version works as strongly as the white-on-black version

## Production work allowed next

Allowed:

- faithful vector reconstruction
- flat transparent master
- optical centering
- safe-area rules
- export sizes
- dark/light variants
- inverted black-on-white variant
- wordmark lockups
- small-size compensation tests
- reduced-mark exploration for extreme sizes only
- controlled partial-bowl-closure A/B test, if needed

Not allowed:

- new logo concepts
- decorative additions
- obvious-letter redesign
- R-first redesign
- casual skewing
- changing slash role
- losing the hidden R
- treating micro-variants as separate brand marks
- open-ended iteration after the controlled A/B test

## Final decision

The master mark remains locked.

The correct strategy is:

1. Canonical master first.
2. Optical compensation for small sizes.
3. Reduced production mark only where the full mark objectively fails.
4. Single controlled partial-bowl-closure A/B test only if R clarity must be challenged.

Do not chase equal D/K/R legibility.

Preserve the stronger system: D/K first-read, slash as identity spine, Z as compressed brand signal, R as discovered
depth.
