# Source Hierarchy Contract

## Status

This root-level source hierarchy contract is superseded by `docs/library/source-hierarchy-contract.md`.

The active contract states that the library tree is navigation-only. Source-file, audio, video, image, companion, and
unsupported file rows belong to contents or explicit diagnostic inventory reads, not tree navigation.

Do not use this document as implementation authority.
